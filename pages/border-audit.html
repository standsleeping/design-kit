Border Audit

Walks each target page and reports two classes of border problem with overlapping ranges. Doubled borders (axes within 1.5px) are the runtime detection corollary of BOUNDARY_OWNERSHIP: exactly one element should own each visible edge. Near-rail borders (horizontal edges 1.5–12px apart with overlapping x ranges, sibling elements only) are the runtime detection corollary of PEER_RAIL's quantization sharpening: chrome strips that look like they're on the same rail must actually share a height (use --chrome-bar-rows on the shell so peers grow together).
