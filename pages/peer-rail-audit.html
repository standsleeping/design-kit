Peer-Rail Audit

Walks each target page and asserts every chrome-rail member (any element computing --peer-rail: chrome) renders at its expected height. The expected height for an element is --layout-chrome-bar-h × --chrome-bar-rows resolved at that element's cascaded position, measured via a probe element inserted in the same DOM so an inner override of --chrome-bar-rows is respected. Members carrying [data-wrap-ok] are allowed to grow beyond the rail height (the floor applies); all others must match within 1.5px. This is the runtime corollary of PEER_RAIL as a declarable contract: each component opts in by adding --peer-rail: chrome to the same CSS rule that binds its height, so the audit finds every member without enumerating class names.
